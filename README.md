# Beyzbol

**Geliştirici: Ahmet Che**

[**Windows için Beyzbol’u indir**](https://github.com/AhmetYTK/beyzbol-releases/releases/latest)

Bu depo Beyzbol’un Windows x64 kurulumlarını ve otomatik güncelleme bilgilerini içerir. Kaynak kodu burada yayınlanmaz.

Windows 10/11 x64 için kurulum EXE’sini indirip çalıştırın. Ek .NET veya geliştirme aracı gerekmez. iPhone’da güncel QR kodunu Safari’de açın; iki cihaz aynı güvenilir Wi‑Fi’de olmalıdır.

1.1.0 ve sonraki sürümler açılışta güncellemeleri kontrol eder, paketi HTTPS ile indirip boyut ve SHA-256 kontrolü yapar. Aktarım yokken uygulama kapatıldığında güncelleme kurulur. Eski sürümlerden geçiş için 1.1.0 veya üzerini bir kez kurun.

Dosya başına sınır 50 GiB. Alınan medya İndirilenler/Beyzbol klasöründedir ve uygulamayı kaldırmakla silinmez. Aktarım yerel HTTP kullanır; şifreli değildir. Kurulum dosyası dijital olarak imzalanmamıştır.
